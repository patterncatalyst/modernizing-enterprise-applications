{%- comment -%} Multi-language code tabs. Emits an empty marker; assets/js/codetabs.js absorbs the next N fenced code blocks (N = number of pipe-separated labels) into an accessible tab group. Because the code blocks stay ordinary Markdown fences, Rouge still highlights them at build time — no plugin required. Usage (place the marker, then one fenced block per label, IN THIS ORDER): {% raw %}{% include codetabs.html langs="Spring Boot|Quarkus" %}{% endraw %} ```java // Spring Boot ``` ```java // Quarkus ``` Ported from cloud-native-design-patterns (same mechanism supports more than two labels if a chapter ever needs it); this project's chapters are Spring Boot → Quarkus migrations, so two labels is the norm. Selecting a tab syncs every group on the page and is remembered across pages. {%- endcomment -%}
